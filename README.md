# 過去問ラボ（自分専用）

偏差値60以上の高校（東京・神奈川・千葉、220校）の入試過去問（英語・数学・国語）を、
偏差値の高い順に見て、画面上で本番のように解き、採点・推定偏差値・合格判定・AI 解説まで行うサイト。

**自分専用。`pdfs/` と `data/crawl.json` は配布・公開しないこと**（入試問題の本文には作家などの著作物が含まれる）。

## 起動

```
python scripts/serve.py 8450
```
→ http://localhost:8450 （Claude アプリでは launch.json の `kakomon`）

## データの作り方

```
python scripts/hensachi.py   # みんなの高校情報から偏差値60以上の高校 → data/hensachi-raw.json
python scripts/crawl.py      # 公式サイトから英数国のPDF → pdfs/ と data/crawl.json（tokyo / jiko / kanagawa を個別に指定可）
python scripts/build.py      # 仕分けして data/catalog.json を作る
```

- 自校作成校のPDFは名前がばらばらなので、build.py がリンク文字・前後の文字・PDF 1ページ目の文字から年度・教科・種類を決める。
  決められないものは `data/unclassified.txt` に出る。手で直すときは `data/overrides.json` に
  `{"pdfs/jiko/…pdf": {"year": 2025, "subject": "数学", "kind": "key"}}`（除外は `{"skip": true}`）。
- 学校がページ上でコメントアウトして隠した古い年度（例：日比谷の令和4・5年度）は取らない。
- 年は「入試を実施した年（2月）」。2026 = 令和8年度入試。2019 = 平成31年度入試。
- 教科別平均点は `data/means.json`（都立共通 2023〜2026。出典は都教委の報道発表）。

## 画面

- 学校一覧：偏差値帯ごと。都県・公私・「問題がある学校だけ」で絞り込み。
- 解く画面：問題／解答用紙／正答表／採点のポイント／台本のタブ。ペン・マーカー・消しゴム・戻す・拡大。
  書き込みはページ幅を 1 とした座標で IndexedDB（`ink`）に保存。印刷・書き込みつきPDF保存（pdf-lib）・元のPDF。
- 本番モード：制限時間（50分）を計り、正答表などを隠す。答えは「解答欄」に入力するか、解答用紙タブに手書き。
  終了時に解答用紙（書き込みつき）を画像にして記録に残す。
- 解答欄：正答表から AI が 1 回だけ作る（`keys` に保存）。記号・数値は自動照合、残りは AI 採点か自己採点（○△×／点数）。
  解答欄がない試験は、正答表を見ながら合計点を入れるだけでもよい。
- 結果：得点・推定偏差値・判定・AI 講評・解説チャット（問題・正答表・採点のポイント・自分の答えを読ませる）。
- 合格判定：教科ごとの最新の推定偏差値の平均＋内申（公立）で、220校を A〜E 判定。

## 推定偏差値（js/grade.js）

数字はすべて決まった式で出す（AI には推測させない）。前提は画面の「計算のしかた」にも出している。
- 共通問題：その偏差値の高校に必要な得点率 p(H) = p60 + (H−60)×slope を逆算。都立共通は p60=74, slope=1.6。
  平均点が基準より低い年は (基準−平均)×0.5 を上乗せ。
- 自校作成：合格ライン 65%、私立・国立：62% を学校の偏差値に対応させ、2.4〜2.5% ごとに偏差値 1。
- 内申：中3の 5段階（主要5教科合計・実技4教科合計）。都立は換算内申、神奈川・千葉は 9教科×3 で近似。
- 偏差値の物差しは「みんなの高校情報」。

## AI（js/ai.js）

- Anthropic の API キーを設定画面で入れる（localStorage）。ブラウザから直接送る（`dangerouslyAllowBrowser`）。
- 既定モデル Claude Opus 5.5。Sonnet 5.5 / Haiku 5.5 に切り替え可。
- 断られたときはサーバー側で別モデルに引き継ぐ（`server-side-fallback-2026-07-01` + `fallbacks: "default"`、Haiku 以外）。
- 解答欄づくり・採点は structured outputs（JSON スキーマ）。解説はストリーミング。PDF は document ブロックで送り、最後の PDF に cache_control。
- vendor/anthropic.mjs は `@anthropic-ai/sdk@1.3.0` を esbuild で 1 ファイルにしたもの。PDF.js は 6.4.299、pdf-lib は 1.17.1。

## 動作確認のしかた

本人は http://localhost:8450 を使う。確認は http://127.0.0.1:8450 で行う（オリジンが違うので記録が分かれる）。終わったらそのタブの IndexedDB `kakomon` と localStorage を消す。
